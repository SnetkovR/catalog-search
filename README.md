# Поиск фотографий в каталоге

Локальный поиск похожих изображений: **DINOv2 Small → FAISS → FastAPI**.
Инференс выполняется только на CPU. Платные API не используются.

Разработка ведется по [плану](PLAN.md), небольшими отдельными коммитами.
Требуется Python 3.12 и [uv](https://docs.astral.sh/uv/).

```sh
uv sync --locked
```

Каталог по умолчанию: `data/catalog`. Пользовательские фотографии и артефакты
обработки исключены из Git.

Модель: [facebook/dinov2-small](https://huggingface.co/facebook/dinov2-small),
лицензия Apache 2.0. При первом использовании потребуется скачать веса;
после загрузки модель сможет работать локально.
